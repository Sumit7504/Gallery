# Gallery Project

This project showcases a responsive image gallery built using HTML and CSS. It displays a collection of images in a grid layout, with captions for each image.

## Features

- **Responsive Design**: The gallery adjusts to different screen sizes for a seamless user experience.
- **Image Captions**: Each image is accompanied by a caption for better context.
- **Clean Layout**: A visually appealing and organized grid structure.

## Project Structure

- **`gallery.html`**: The main HTML file that structures the gallery and includes the images with captions.
- **`gallery.css`**: The CSS file that styles the gallery, ensuring responsiveness and a clean design.

## How to Use

1. Clone the repository or download the project files.
2. Open the `gallery.html` file in your browser to view the gallery.
